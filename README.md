# TenderSathi

A free-to-run, multi-agent AI system that helps Nepali SMEs find and qualify for
government tenders on bolpatra.gov.np.

See [CLAUDE.md](./CLAUDE.md) for the full problem statement, architecture, tech
stack, and phase roadmap.

## Quickstart

```bash
uv sync --all-groups
cp .env.example .env   # then fill in the keys described in .env.example
uv run pytest
```
